# Configuration Guide

Effective order: BASE CONFIG -> PROFILE -> EXPERIMENT OVERRIDE -> USER/GUI OVERRIDE -> EFFECTIVE CONFIG.

Base files: config/scene_config.m, config/robot_config.m, config/planner_config.m, and visualization configuration. Named profiles are resolved by experiment_config_builder or config/resolve_effective_config.m. Robot geometry, footprint, DH parameters, joint limits and reachability bounds are fixed to robot_config.m; conflicting overrides are rejected by validate_main_robot_config. The legacy_validated profile name is an identical compatibility alias. Scene layout/scale, routing mode, sparse k, candidate sampling/weights, augmentation and visualization can be declared experiment variables. Formal comparisons enforce nominal geometry, the main threshold 0.30, return to start, and fixed visit order for path-algorithm comparisons; conflicting threshold/return overrides are rejected. Low-level diagnostic fixtures can test other bounds, but do not count as formal comparisons. See main_robot_unification.md for removed models/scenes and geometry_protocol_evidence_repair.md for the current protocol and evidence boundaries.
