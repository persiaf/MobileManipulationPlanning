# 几何、实验口径与方法证据修复说明

本轮按用户指定的顺序修复：先几何与场景，再实验口径，最后实际运行方法验证。本文对应2026-10-27参数清理之后的版本；旧报告中的数值不自动成为本版本的实验依据。餐厅场景和另一套实机模型保持删除，未恢复第二套机器人参数。

## 1. 几何与场景

| 问题 | 修复及含义 |
|---|---|
| 旋转桌面栅格与任务坐标不一致 | 修正矩形栅格掩码的Y轴符号；任务、桌面归属检查和动态新增任务统一使用桌面局部坐标到世界坐标的旋转。显式桌号必须与旋转矩形中的位置一致。 |
| 底盘长宽轴与朝向混淆 | 机器人局部X轴对应长度0.423 m，Y轴对应宽度0.366 m。碰撞检查使用连续位姿下的矩形与占用栅格方块的分离轴判定，接触也判碰撞；修正圆形兼容检查误用空闲格的问题。 |
| 候选输入被覆盖 | 修正 `compute_reachability_field` 的 `nargin` 判断，使调用者传入的质心、任务位置真正参与计算；增加可验证的朝向采样步长，保留默认15°。 |
| 实机任务坐标与另一套模型 | 上一阶段已删除不一致的专用场景。现有通用场景构建入口检查任务是否位于声明桌面的旋转矩形内；没有用导航占用图判断桌面任务是否合法，也没有为保留旧场景而改主机器人。 |
| 冻结状态与显示场景不符 | V/L命名场景按请求的配置构建，不再把V场景换成L场景，不再以示意直线兜底。缓存键绑定地图、任务、配置、机器人和实现源码；不匹配时拒用或重新生成。历史P3/P4下游重放也检查实现身份。 |
| 栅格路径未到达真实停靠位姿 | 给搜索路径补充经过原场景图校验的短连接段，保留请求的XY和yaw；无法连接时返回失败，不用格心替代停靠点。平移采样不大于分辨率/3，旋转不大于5°，显式检查原地转向。 |
| 路径记录与最终执行路径脱节 | 最终路径必须等于各段路径的精确拼接，各段端点必须吻合访问位姿；验证时重新采样SE(2)，可以拦住“段路径正确但最终路径绕过停靠点”和“只检查旋转两端”的反例。 |
| 新增任务后状态不完整 | ADD_TASKS更新受影响桌面的候选库、任务映射、服务配置、预测任务集和当前计划，保留已下发/已执行/已验证集；原始RC2计划和原始Map对象不被修改。 |

导航搜索使用包含占用单元面积和地图边界的保守膨胀；候选与连接段使用实际矩形足迹检查。这里的“原图”是已有安全带的 `scene.grid_map`，不是未经膨胀的真实物理环境。因此净空值不能解释成实测物理间隙。路线模型仍是几何上的全向移动与原地转向，未新增底盘动力学或闭环跟踪证明。

## 2. 统一实验口径

机器人继续唯一取自 `config/robot_config.m`：底盘0.423×0.366×0.127 m，双臂间距0.250 m，安装偏移0.2115 m/0.1833 m，单臂水平半径0.278 m，原DH字段和关节限位不变。该文件SHA-256仍为 `34c59d92d6ce8b77684f59cb1003d0f33abab80f3f1e64b8e5914a5e79ec247e`。

正式对比由 `apply_experiment_protocol` / `validate_experiment_protocol` 固定主评分阈值0.30、nominal几何模式、返航和固定访问顺序的路径算法对比口径；冲突覆盖显式报错。场景、采样、权重、路由方式和被比较算法可以作为已声明的实验变量。低层人工测试夹具可以单独测试边界，不属于另一套实验机器人。

| 指标 | 证据要求 |
|---|---|
| 代理覆盖 | 需要显式代理来源及任务ID；没有代理证据则为NaN。 |
| 几何覆盖 | 当前几何模型和阈值下的任务可达评分，分母为全部任务。 |
| 仿真几何完成 | 仿真执行器对计划任务再次进行几何验证；不等于实机完成。 |
| IK可行 | 需要独立IK验证证据；现版本结果为NaN。 |
| 实际完成 | 需要测量执行与任务验证证据；现版本结果为NaN。 |

不再把未被候选覆盖的任务直接称为“模型不可行”并从分母剔除；旧可操作性接口的此类分母标记为未经独立验证。未知耗时不补零，部分覆盖也不能直接产生全任务成功记录。

主规划计时为场景构建、候选生成、停靠选择、路径代价、访问顺序、路径拼接和路线校验之和，排除执行模拟、独立审计、绘图与结果文件写入。`routing_time_s`已经包含`path_validation_time_s`，后者是子项，不能重复相加。路由失败仍记录实际尝试耗时，独立几何审计继续运行。

路径算法benchmark分别记录请求算法、可观察的实际算法、逐次查询、返航、失败段与计时范围。固定访问顺序的路径比较与独立重排的路线管线比较单独标识。Convex内部回退无法观察时标为未知，不能据此宣称所有路径都由纯Convex算法产生。

动态实验已移除估算的“全量重规划参考”：两分支使用同一个事件后场景，真实执行局部与完整重规划。内部路径验证计入双方重规划；额外的同函数成对认证在双方计时之后单独记录。路径查询统一统计所有尝试候选图的请求，包括缓存命中和被拒候选；异常中途无法确认的次数标未知。成对MAT保留原状态、事件后状态、两分支结果和认证。

## 3. 方法证据设计

`run_repair_evidence_suite`先丢弃一轮预热，顺序运行各组。种子为2026、2027、2028。静态和补充权重案例保存实际输入、配置、实现签名与逐任务独立审计；动态基础状态另做独立审计，两分支保存路线认证和成对证据。历史输出保留。

| 组别 | 设计与边界 |
|---|---|
| 主场景参考 | 原主场景16桌，3种子；不为提高成功率改机器人、任务位置或布局。 |
| 采样与权重 | C2的显式4桌受控子集SENS4；每种子15个设置，共45例。基准加沿边/法向/朝向/栅格各两档，以及候选可达/候选覆盖/选择覆盖三个原始权重的0.5和2倍。每种子连续桌面和任务几何签名必须相同。 |
| 完整复杂场景 | 原C0–C3完整配置各3种子，共12例；保留其布局和任务分布。跨C0–C3比较是整个场景的比较，不能单独归因于旋转。 |
| 动态对照 | 主场景任务分布的显式4桌子集MAIN4；3种子×3事件×局部/完整，共计划18行。若基础计划失败，记录BASE_BLOCKED，不伪造事件对照。 |

采样基准为沿边0.15 m、法向0.05 m、朝向15°、地图0.05 m；两档分别为0.20/0.075 m、0.075/0.025 m、30°/7.5°、0.10/0.025 m。栅格变体也会改变安全带取整近似，不能解释成只改变搜索分辨率。权重在使用前归一化，倍率实验会改变其它项的归一化占比，不能说其它最终占比完全不变。

独立可达性实现重新推导世界目标向底盘/双臂基座的投影、工作空间边界和评分，不调用生产评分器。对候选库逐对核对；未覆盖任务再进行桌面坐标下0.025 m平移、5°朝向、±90°范围的有限搜索，并验证足迹。找到的安全位姿是当前几何模型的反例/覆盖见证；找不到只能写“审计采样中未找到”，只有违反不随平面位姿变化的硬高度界才给对应几何证书。

现有DH字段不足以唯一确定完整FK/IK链，也没有URDF或经过验证的IK适配器。因此这次独立验证属于独立实现的几何交叉检查，不是完整运动学、机械臂避碰或实机证据。

### 主场景与完整复杂场景

下表覆盖率取三个种子的算术平均；路径长度只统计成功的完整路线。成功要求全部任务覆盖以及路径足迹、端点和拼接校验通过。

| 场景 | 完整规划成功 | 几何覆盖均值 | 成功路线平均长度 | 解释 |
|---|---:|---:|---:|---|

MAIN说明停靠选择与导航连接之间仍缺少充分的联合约束：单点可服务并不保证所有服务位姿能由当前导航管线连接。保守搜索膨胀和有限端点连接也可能漏掉有效运动，因此 `BLOCKED_ROUTING` 不能解释为物理不可达证明。

C2的220个任务中，独立密集搜索额外找到19个任务的安全几何见证，宏平均审计支持率升至84.47%；另34个任务仍未在有限搜索中找到支持。这给出了候选采样遗漏的直接证据。C3的任务模式与C2不同，部分任务更靠近桌边；当前结果不足以把场景编号当成单调的任务难度等级。

### 45组采样与权重敏感性

45例全部在覆盖阶段阻断，因此下列耗时是场景、候选与选择到阻断为止的开销，未包含完整路线规划，不能报告成完整任务加速比。

| 设置 | 覆盖率均值 | 阻断前开销均值 |
|---|---:|---:|
| 基准 | 69.08% | 7.78 s |
| 沿边粗 / 细 | 64.64% / 70.53% | 4.25 / 29.30 s |
| 法向粗 / 细 | 65.41% / 70.93% | 4.59 / 22.81 s |
| 朝向粗 / 细 | 65.01% / 69.08% | 3.56 / 17.88 s |
| 栅格粗 / 细 | 14.35% / 71.61% | 7.09 / 9.18 s |

加密采样没有稳定地带来相称的覆盖提升，栅格离散近似则对这些短臂桌面任务影响很大。固定阈值下，权重不能生成候选库中不存在的覆盖见证。六个权重变体的覆盖率均与同种子基准相同；`selection_coverage_half`使2027种子的停靠数从15增至16，其它所列设置的停靠数保持一致。对此只能报告当前范围内的观测，不能据此宣称权重无关或已经找到最优权重。

为进一步检验完整路线上的权重效应，另完成MAIN4的21例补充批次，保留独立预热、批次标识和配对几何检查，单独汇总，不把两批的绝对耗时混在一起。21/21例均为100%覆盖、完整安全路线；在每个种子内，基准及六个倍率变体均选6个停靠，路径长度也相同：2026为30.410 m、2027为25.637 m、2028为29.719 m。18组变体/基准配对全部满足同批次和同源码条件，独立评分不一致数为0。

这个补充说明当前MAIN4子集在所测0.5–2倍范围内没有表现出路径或停靠数量变化；它没有区分这些权重设置，不能证明其它任务分布下权重同样不重要。几秒级耗时的小幅波动不足以作为某组权重更优的证据。见 [独立补充汇总](../results/repair_20261027/evidence_20261027_221823/weight_completion_supplement/weight_completion_analysis_summary.json)。核心78行与补充21行合计99行，两份完整性检查均为有效、数据质量问题0。

### 独立审计、保存修复与复现

核心静态60例均审计PASS，报告的候选对评分不一致数为0。加上三个动态基础状态，共63份逐任务审计、1,872个任务案例观测：1,531个库内覆盖、128个采样遗漏见证、213个有限搜索未找到支持。变体中的重复任务是重复观测，不是1,872个独立物理任务。所有IK和实际完成字段继续为NaN。

## 5. 仍需保留的研究边界

当前几何任务高度0.50 m距配置的高度上界0.5173 m仅0.0173 m，适用范围受工作空间和评分边界影响。统一参数保证比较使用同一模型，并不保证所有任务分布可行。后续改进应围绕导航可接入的停靠选择、由独立见证引导的候选补采样，以及具备完整关节变换链后的IK与机械臂避碰验证展开；本轮没有通过放大机器人工作空间或降低阈值消除失败。

这些实验是3种子的先导证据；它们可以说明采样、权重和当前几何实现的敏感性，不能替代大规模统计、完整IK验证、动力学约束或真实机器人实验。
