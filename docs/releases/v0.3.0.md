- 使用 `main_mobile_manipulation_planning.m` 对应的唯一机器人配置，保留全部主机器人数值；移除餐厅、实机匹配场景及冲突模型。
- 修正旋转场景、底盘长宽轴、占用栅格面积、候选参数判断、任务归属与新增任务坐标；校验真实停靠端点、旋转中间姿态和最终路径的分段来源。
- 冻结场景绑定输入与实现身份；正式比较固定0.30阈值、返航和计时范围。代理覆盖、几何覆盖、仿真完成、IK与实际完成采用独立证据字段。
- 动态对照真实运行局部/完整重规划，新增任务同步服务指令、候选与任务状态；成对MAT使用紧凑证据快照、重载检查和先提交MAT再写CSV。
- 维护README、研究边界、参数清理清单、118项定向测试与99条实际实验记录的可追踪关系。
