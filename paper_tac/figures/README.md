# Manuscript figures

This directory contains the nine assets referenced by the revised manuscript.
PDF sources are used when a vector version exists; the main scenario scene is
kept as PNG because no same-name PDF was found in the repository.

The source-of-truth locations and panel purposes are recorded in
`../docs/FIGURE_MANIFEST.md`. Do not edit the archived files under
`../results/figures/tac_submission/` when updating this directory.
