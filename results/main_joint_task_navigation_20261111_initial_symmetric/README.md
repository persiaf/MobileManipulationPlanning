# 初轮导航失败记录

本目录保留第一次完整主场景运行：12 个案例均已记录，其中仅位置约束的 4 个案例有效；抓取与擦拭的分阶段案例在路径拼接时失败，后续控制因缺少有效种子而阻塞。失败代价为 NaN，不能与成功路线计算下降率。`independent_audit.json` 为 `PASS_WITH_RECORDED_FAILURES`，表示记录通过审计，并不表示所有任务成功。

初轮沿用历史 dense 矩阵的单向查询后镜像和单次最近邻。诊断确认导航查询具有方向相关的有限搜索失败，且同一停靠集合存在有效的其他访问顺序，详见两个 diagnosis JSON。它不证明机械臂或底盘物理不可达。

最终四方法统一采用真实有向矩阵和按固定节点顺序取首个有限最近邻闭环；复用本目录完全相同的任务、候选和三模式 IK 库，结果位于相邻的 `main_joint_task_navigation_20261111/`。共同导航修复不能算作联合选位收益。

`source_snapshot/*.m.txt` 保存初轮入口及导航代码的文本快照，避免被 MATLAB 当作可执行路径。`figures/` 是运行中仅位置组完成时生成的早期预览，不是初轮全部 12 个案例的最终图，其 manifest 保存的是当时的输入状态。正式可视化请使用最终结果目录。
